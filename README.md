# Renewly

A free, private subscription tracker. See what your subscriptions really cost per month and per year, and when each one renews.

- No account, no server: data is stored only in your browser (localStorage).
- Export to CSV or back up and restore as JSON.

## Run locally

Open `index.html` in a browser. There is no build step.

## Deploy

It is a static site (`index.html`, `style.css`, `app.js`), so it deploys as-is on Vercel, GitHub Pages or any static host.
